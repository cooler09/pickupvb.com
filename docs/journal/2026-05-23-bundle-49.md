# Bundle 49 — Architecture P3 cluster closeout: JSDoc, hrefs, barrel-export docs (2026-05-23)

## Context

After Bundle 48 closed the documentation-audit deliverable, the
architecture audit's [Still open](../audits/architecture.md) list had
two entries: the deferred **P2 mapper extraction** (blocked on a
`group_members` DTO-shape design call) and the **P3 cluster** —
"JSDoc on aggregate factories, hrefs cleanup, barrel-export docs."

The P3 cluster was a natural single bundle: three small, mechanical
items that share a documentation-quality theme and whose combined
footprint stays under the size of one well-scoped P2. Landing them
together also lets the audit row collapse to a single open finding,
which is materially easier to triage in future audit sweeps.

### Hrefs cleanup — verified already-done

The original audit flagged string-concatenated route hrefs as a P3
typed-routes regression. A grep for
`href={['"][^'"]+['"] ?\+` and
`['"]/(events|groups|teams|players)/['"] ?\+` across
`apps/web/src/` returned no genuine matches — the only hit was
`hrefFor(page + 1)` in
[pagination.tsx](../../apps/web/src/components/pagination.tsx#L82),
which is arithmetic on a numeric page index, not href concat. The
events/[id] page-diet work in Bundles 23-24 (and the various
co-located action refactors since) already cleared the offenders the
audit was written against. Recorded the verification in the audit
remediation log so the next agent doesn't repeat the grep.

### Barrel-export docs — one paragraph per package README

Added a new `## Exports` section to each of the three workspace
package READMEs documenting what `src/index.ts` actually re-exports
and the contract for adding new entries:

- [packages/domain/README.md](../../packages/domain/README.md) —

  `teams/`, `brackets/`, `payments/`, `community-listings/` all
  forwarded as-is).
- [packages/application/README.md](../../packages/application/README.md)

- [packages/infrastructure/README.md](../../packages/infrastructure/README.md)
  — per-adapter listing; only adapter classes/factories are public,
  internal mappers stay file-private.

## Patterns / follow-ups

- **Audit P3s bundle well when they share a closure window.** Three
  loosely-related P3s that would each have produced a forgettable
  one-line journal entry compress into a single readable bundle —
  worth doing whenever the bundle stays under a P2's normal
  footprint.
- **Audit text can outpace the code.** The hrefs P3 had already been
  silently resolved by earlier refactors; the only deliverable left
  was the verification + remediation-log note. Worth always doing
  the cheap grep before assuming an audit finding still applies.
- **The architecture audit is now down to one open finding.** The
  P2 mapper extraction is genuinely blocked on the `group_members`
  DTO-shape question (one mapper with optional fields vs. two
  shape-specific mappers). Pick this up only with a design-call
  preamble.
