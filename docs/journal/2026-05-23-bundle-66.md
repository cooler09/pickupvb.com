# Bundle 66 — 2026-05-23 — Events page UX audit stale-note reconciliation

## Context

After Bundle 65 closed the last P3 in the Organization audit (Node
22 LTS bump), the per-audit "open" list in
[docs/audits/README.md](../audits/README.md) had no truly small open
findings left. The remaining items are all either large
(Performance ISR refactor, SEO slug-URL migration, Security P3 #8
audit-log table, Architecture mapper extraction remainder, Security
P2 #3b nonce CSP) or blocked on a design call / external decision
(Architecture group-member mapper, Organization remote Turbo cache,
Registration captain-claim affordance).

What _was_ still open: the Events page UX audit's status row in
the README said "Closed UX; architectural regression noted
2026-05-22" — dated five months stale. The 2026-05-22 status block
inside the audit itself flagged two follow-ups "for the next
page-diet pass":

1. Page LOC regression: the page had grown to 837 LOC (against a
   ~520 baseline at the time of the original audit).
2. `Date.now()` in render at `page.tsx#L115` — a React Compiler
   purity violation.

Both were filed against the parent **architecture** and
**performance** audits respectively. Five months on, both parent
findings have been closed. The events-page-ux audit just never got
the reconciliation note.

Smallest possible bundle, but a real bit of stale-doc cleanup so
the next agent scanning the README doesn't go "what regression?"
and chase shadows.

## What shipped

Audit-doc reconciliation only — no code edits.

### Verifications

- **Page LOC.** `wc -l apps/web/src/app/events/[id]/page.tsx` →
  **296**. Was 837 when the 2026-05-22 note went in. Architecture
  audit Bundles 23 + 24 closed it (Bundle 23: data loader
  extraction, 887 → 566 LOC; Bundle 24: six `_components/`
  extractions, 566 → 294 LOC).
- **`Date.now()` sites.** `grep -r 'Date.now()' apps/web/src` →
  zero matches. Performance audit Bundle 2 closed it by adding
  [render-now.ts](../../apps/web/src/lib/render-now.ts)
  (`renderNowMs()`) and lifting `EventHero`'s time-derived
  booleans to the page boundary as a `closingSoon` prop. The
  specific `page.tsx#L115` site the prior note named is gone with
  the page-diet refactor — there's no line 115 anymore.
