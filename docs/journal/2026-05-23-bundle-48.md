## Why this is worth recording

The headline finding is that **the codebase has zero deferred-work
annotations**, which is itself a notable signal: the team's been
either fixing things in the moment or capturing follow-ups in the
audit / journal files instead of leaving inline `TODO`s. The
documentation audit's recommendation now reads as a one-line standing
check ("re-run the same grep at the next documentation audit to
confirm the trend holds") rather than an open promise.

## Pattern notes

- **A grep can be a remediation.** Not every audit deliverable is code
  or prose — sometimes the answer is "the thing the audit feared
  doesn't exist," and the only output is the recorded scan result so
  the next reader doesn't re-do it.
- **Historical comments aren't TODO debt.** The user-picker.tsx note
  about a removed blur-timing hack is the kind of in-code annotation
  worth keeping — it explains _why_ the current code looks the way it
  does. The grep regex was deliberately scoped to leading
  comment-prefix patterns (`// TODO`, `-- FIXME`, etc.) to avoid
  flagging this kind of prose.
