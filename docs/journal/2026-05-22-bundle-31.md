## Patterns surfaced

- **Library-landmarks table** is a useful shape when a package has more
  than ~5 single-purpose helper modules under one `lib/`. A bare layout
  snapshot doesn't convey which files are load-bearing; a 6–8 row table
  with a one-line role per file does. Worth borrowing if/when other
  packages grow a similar surface.
- **Cross-link rather than restate.** The README's "Conventions"
  section deliberately mirrors AGENTS.md instead of forking. Anything
  longer than a one-line recap belongs in AGENTS.md so there's a single
  source of truth that the bundle journal entries can keep updating.
