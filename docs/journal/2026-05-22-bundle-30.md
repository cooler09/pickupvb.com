## Patterns surfaced

- **Layout snapshot first, rules second.** Every package README opens
  with the `src/` layout the reader will see when they `cd` in. The
  rules and pointers come after, anchored to that layout. Domain's
  README set this shape and it transfers cleanly to every other
  framework-free package.
- **One-line `eslint.config.mjs` re-export** is the canonical wiring
  for the shared base config. Surfaced as a snippet in the config
  README so contributors don't have to grep an existing package to
  discover it.
