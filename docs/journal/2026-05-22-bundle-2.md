# Bundle 2 — React Compiler lint, focus trap, FieldError, postcss override (2026-05-22)

## Context

Second remediation sweep, picking up the follow-ups left by Bundle 1.
Four threads:

- **A.** React Compiler lint warnings (`react-hooks/purity` +
  `react-hooks/set-state-in-effect`) firing across server and client
  components — [docs/audits/performance.md](../audits/performance.md) P1.
- **B.** No shared accessible form-error primitive; each form re-implemented
  `<FieldError>` and most omitted `aria-invalid` / `aria-describedby` —
  [docs/audits/accessibility.md](../audits/accessibility.md) P2.
- **C.** Mobile menu drawer had no focus trap and no `role="dialog"` —
  [docs/audits/accessibility.md](../audits/accessibility.md) P1.
- **G.** `postcss` transitive advisory — [docs/audits/security.md](../audits/security.md) P2.

## Decisions

- **`renderNowMs()` helper over per-line disables for purity.** Server
  components read `Date.now()` once per render to derive "is this in the
  past?" booleans. That's semantically pure within a request but the
  compiler can't prove it. Wrapping the read in
  [apps/web/src/lib/render-now.ts](../../apps/web/src/lib/render-now.ts)
  gives the rule a single explicit "this read is intentional" site and
  documents intent reusably. Rejected scattering `eslint-disable` because
  it doesn't communicate why future readers should keep doing this.
- **Lift derived booleans to props at the page boundary, not in the leaf.**
  `EventHero` was computing `closesAtMs` mid-render. Moved the
  computation to [events/[id]/page.tsx](../../apps/web/src/app/events/[id]/page.tsx)
  and passed `closingSoon: boolean` down. Keeps the leaf purely
  presentational and gives the rule nothing to flag.
- **`useIsMounted()` via `useSyncExternalStore` over `useState+useEffect`.**
  Three components used the classic `useState(false) + useEffect(() => setMounted(true), [])`
  hydration flag, which trips `react-hooks/set-state-in-effect`. The
  React-Compiler-blessed equivalent is
  `useSyncExternalStore(noop, () => true, () => false)`. Extracted to
  [apps/web/src/lib/use-is-mounted.ts](../../apps/web/src/lib/use-is-mounted.ts).
  Rejected per-component disables: pattern is common enough to deserve a
  named primitive.
- **Per-line disables + rationale comment for debounce-fetch effects.** Two
  autocomplete components legitimately need to `setState` in an effect to
  clear stale results when the input drops below the min length. There's
  no cleaner primitive ("debounce + fetch + display" is inherently
  imperative). Kept one disable per effect with a `--` rationale.
- **Shared `FieldError` + `fieldA11y()` extracted to
  [apps/web/src/components/field-error.tsx](../../apps/web/src/components/field-error.tsx).**
  `fieldA11y(name, errors)` returns `{ 'aria-invalid', 'aria-describedby' }`
  to spread onto the input. Rejected sweeping all 6 forms in this bundle —
  migrated 2 to validate the API, deferred the other 4 to keep the bundle
  scoped.
- **`pnpm.overrides` for postcss over waiting for upstream patch.** Risk
  is low (postcss is widely used at this version), the advisory is real,
  and overrides are the standard pnpm escape hatch. `pnpm audit` now
  shows 0 vulns.
- **Mobile menu: full focus trap, not just initial focus.** Drawer now
  has `role="dialog" aria-modal="true" aria-label="Main menu"`, focuses
  the first focusable on open, and cycles Tab/Shift+Tab via a
  `FOCUSABLE` selector. Rejected portal-based modal libraries — the
  drawer is already a small surface, adding a dep wasn't justified.

## Patterns observed

- **The React Compiler purity rule fires on server components too.** Even
  one-shot reads at server-render time get flagged. Wrap them or lift
  the derived value to the boundary.
- **Lint rules fire at call sites, not opener lines.**
  `// eslint-disable-next-line` above the `useEffect(` opener does
  nothing — put it directly above the offending `setX(...)` line.
- **The setState-on-mount pattern was everywhere.** Now solved with the
  shared `useIsMounted()`. Future hydration flags should use it.
- **When converting "compute A from B" → "accept A as prop", grep the
  whole leaf for B before declaring victory.** First pass missed a
  trailing reference to `closesAtMs` and broke the build.
- **The codebase lacked a shared a11y form primitive.** Each form rolled
  its own `FieldError`. Establishing one shared component pays off
  across all future forms.

Patterns durable enough to promote to AGENTS.md "Patterns surfaced by
audits" can be added next bundle; the section already has 6 rules and
adding more now would dilute it.
