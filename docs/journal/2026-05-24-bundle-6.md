# Bundle 6 — Team-paradigm ADR (audit step 1 closeout)

_Date: 2026-05-24_

## Context

Bundle 5 ([journal](2026-05-24-bundle-5.md)) closed the last P1 leftover
on the registration-workflow audit. The only doc-only blocker still open
was **recommended sequencing step 1** — "decide on the team paradigm
split (ad-hoc vs. roster) at the product level. _Write an ADR._"

ADR 0007 already decided the paradigm in §1 — but it bundled three
concerns (paradigm + division-first registration + `price_unit`
checkout) into one record, and Bundles 1–5 had since diverged from
0007's predicted shape in non-trivial ways (the `EventTeamPayment`
sidecar in Bundle 4, the side-step `attach*ToDivision` ports across
Bundles 1 & 5). A focused successor ADR was warranted so the next agent
doing the larger single-flow UX refactor doesn't have to re-derive the
paradigm decision from five journal entries.

## Decisions

- **Focused successor ADR over editing 0007.** ADRs are immutable
  (per [adr/README.md](../adr/README.md)). 0008 ratifies §1 of 0007 and
  records the post-implementation patterns; 0007 stays as the
  historical decision spanning all three bundles.
- **Promote "side-step the aggregate" to documented doctrine.** Two
  instances (`attachTeamToDivision`, `attachFreeAgentToDivision`) is
  enough to write it down. Recorded in 0008 §4 with a revisit
  condition. Worth a follow-up promotion into AGENTS.md "Patterns
  surfaced by audits" if a third instance lands.
- **Re-affirm two-aggregate split.** Considered re-litigating after
  ad-hoc shipped (Bundle 2/3); the lived experience strengthened the
  case — invariants and lifecycle diverged more than predicted.
- **Declare ad-hoc audit closed by discovery.** No code changes needed
  — grep verified the full path (handlers, panels, host UI, division
  integration) is wired up. Removed from the implied follow-up list.

## Patterns observed

- **Audit step 1 is a doc-only bundle that unlocks UX P2 work.** The
  collapse refactor (`TournamentRegistrationTabs` → single flow) was
  blocked on the paradigm being citable. Now it isn't.
- **0007's "Recommended sequencing" prediction held up.** The five
  bundles shipped in roughly the order 0007 §"Migration order"
  proposed. Worth recording in 0008 that the bundling was correct even
  if the bundling _per record_ was a mistake (we should write
  narrower ADRs going forward — one decision per file).
- **The `[id]` glob trap is still active.** Used `grep_search` with
  explicit `**/*.{ts,tsx,sql}` to find ad-hoc references; bare
  `file_search` for files under `apps/web/src/app/events/[id]/` still
  needs the bracketed-path workaround (`grep -rn` via the terminal).
