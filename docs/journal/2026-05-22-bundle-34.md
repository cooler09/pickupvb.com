## Patterns surfaced

- **Audit findings drift faster than the audit doc.** This was the
  third finding in three bundles where the audit's stated premise was
  already wrong by the time the bundle landed — Bundle 32's
  server-actions doc was "already in AGENTS.md", Bundle 32's
  audits-index row had "been there since 2026-05-17", and now Bundle
  34's "no tests exist anywhere" was resolved by Bundle 22. The
  remediation log entries explicitly note the staleness so a future
  reader can see why the doc was added in a different shape than the
  original audit suggested. Worth keeping the "doc what's actually
  there, not what the audit assumed" pattern.
- **One doc, multiple audits.** The testing-strategy doc closes the P2
  in [documentation.md](../audits/documentation.md) but also serves as
  the canonical reference the **architecture audit's resolution
  note** points to (Bundle 22 left "see also: testing doc" as an
  implicit follow-up). No separate cross-update needed — the arch
  audit's `✅ Resolved 2026-05-22` line is already accurate.
- **Playwright config is good documentation when it's well-commented.**
  The doc could have re-derived the auth-setup + storageState dance
  from scratch; instead it links to the config file and lets the
  inline comments there speak. Keeps the doc terse and the source of
  truth singular.
