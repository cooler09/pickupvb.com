# 2026-05-24 — Bundle 18: BreadcrumbList JSON-LD on detail pages

## Context

After shipping Bundles 14-17 across the security audit, the user asked
to move to the next audit. The performance audit's remaining P1 #1
items (events-listing per-viewer Suspense refactor, detail-page overlay
strategy) are too large for a single bundle. The architecture audit's
P2 backlog (server-action `revalidatePath` gaps; `profile/billing/actions.ts`
bare `Error()` sites) was verified during scoping and **both findings
are stale** — the flagged files now use the correct patterns (see
"Audit impact" below). That left the SEO audit's P3 row "Add
`BreadcrumbList` JSON-LD on detail pages" as the cleanest, smallest,
fully-contained remediation — four detail pages, one shared component.

## Decisions

- **Single shared component, not per-route co-located.** The existing
  `EventJsonLd` lives under `events/[id]/_components/` because its
  schema (SportsEvent) is event-specific. `BreadcrumbList` has the
  same shape on every route — 3 items, name+url — so a top-level
  `apps/web/src/app/_components/breadcrumb-jsonld.tsx` avoids four
  near-identical copies and gives the next consumer (a future
  `community/[slug]` detail, etc.) a one-line drop-in. AGENTS.md
  warns against helpers for one-time operations; four call sites is
  comfortably past the threshold.
- **Include "Home" explicitly as the first item.** Google accepts
  either form, but explicit Home makes the SERP trail render as users
  expect ("PickupVB › Events › My event") rather than starting at the
  listing.
- **Absolute URLs in every `item` field.** Per the BreadcrumbList
  spec, relative URLs are ignored — Google Search Central explicitly
  calls this out. Using `https://pickupvb.com/...` matches the
  existing `EventJsonLd` pattern (which already emits absolute URLs).
- **Teams page uses `params.id` not `team.slug`.** The teams page
  selects `'id, name, format, captain_id, extra_member_count'` — slug
  isn't in the projection. The existing `returnPath` and `ShareLink`
  references to `team.slug` are pre-existing bugs that emit
  `undefined`; not in scope for this bundle, but the breadcrumb URL
  uses `params.id` (which IS the slug, since the lookup is
  `.eq('slug', params.id)`) so the rich result renders correctly even
  while the in-page links are broken. Logged as a follow-up.
- **Events page guards with `event.visibility === 'public'`.** Matches
  the existing `EventJsonLd` guard — no point advertising a
  breadcrumb trail for a page that's `noindex` anyway.
- **Teams page still emits JSON-LD despite the login redirect.**
  Teams pages redirect unauthenticated users to /login, so a real
  crawler never reaches the JSON-LD. But the page is in `sitemap.ts`,
  meaning the intent is for it to be indexable — the login-gate is a
  separable regression. Emitting the breadcrumb keeps the right
  behavior the moment the gate is removed; no harm meanwhile.

## Follow-ups deferred

- **Teams page `team.slug` is `undefined`.** Pre-existing — the SELECT
  in `apps/web/src/app/teams/[id]/page.tsx` doesn't include `slug`,
  but two existing sites (`returnPath`, `ShareLink path={...}`)
  reference it. Likely produces `/teams/undefined` at runtime. Worth
  a follow-up bundle to either add `slug` to the projection or switch
  to `params.id`.
- **Teams page login redirect vs. sitemap inclusion.** Teams are in
  `sitemap.ts` but the detail page redirects unauthenticated viewers
  to `/login`. Either the gate should drop, or teams should be
  removed from the sitemap. Worth a discussion entry.
- **Architecture P2 backlog is stale.** Verified during Bundle 18
  scoping that all six files flagged by "Server-action files missing
  `revalidatePath` after mutation" now use the correct patterns
  (Stripe-redirect actions defer to webhooks; non-Stripe wrappers
  delegate to handlers that already revalidate; one is read-only).
  `profile/billing/actions.ts` likewise throws `InvariantViolation` /
  `UnauthorizedError` everywhere — no bare `Error()`. Both findings
  should be re-graded as resolved in `docs/audits/architecture.md`.
- **SEO P3 still open:** `SportsTeam` / `SportsOrganization` JSON-LD
  on teams + groups pages. Slug-based event URLs (non-trivial
  migration). `BreadcrumbList` shipping makes these the next obvious
  rich-result wins, but neither is small enough to pair with this
  bundle.
