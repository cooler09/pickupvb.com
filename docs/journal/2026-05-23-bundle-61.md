## Pattern notes

### Wontfix-gated families: three flavors in use now

Closures with a gate condition are now a family. Distinguishing
the gates makes re-opening easier when the world changes:

- **Wontfix-gated-on-release-cadence** (Bundle 60: CHANGELOG /
  changesets). Trigger: any release event needing a stable version
  label.
- **Wontfix-gated-on-complexity-growth** (Bundle 61: flow diagrams).
  Trigger: a contributor reports needing to read 3+ source files to
  understand a single flow, or a new flow that resists prose.
- **Wontfix-by-design** (Bundles 53 / 54 / 58 / 59). No external
  gate — the choice is the opposite of the audit's fix and would
  stay closed unless the rationale rots.

Pattern to follow: name the gate in the closure header so a future
auditor can scan for the trigger condition without re-reading the
rationale.

### "Audit fully closed" is a milestone worth flagging

Documentation is now the first audit to reach full closure (every
P1 + P2 + P3 either Fixed or Wontfix). That's worth saying loudly
in the audits-index row — both because it changes how a new
contributor reads the row (no backlog to mine) and because it sets
the bar for what "done" looks like on the other audits.

Track this as a column-shape change: the audits-index row format
implicitly assumed every audit had a backlog. The Documentation
row now leads with **✅ Fully closed** instead of a finding
summary. Worth mirroring as other audits approach completion.

### Closing the doc audit confirms the journal-replaces-CHANGELOG bet

Bundle 60 closed CHANGELOG on the grounds that [docs/journal/](../journal/)
covers per-bundle rationale at greater depth. Bundle 61 closes
flow diagrams on the grounds that prose + JSDoc + ADR cover the
flows at greater depth. Both rely on the same load-bearing
assumption: **rich narrative artifacts substitute for rigid format-
specific ones**. Worth re-checking the doc artifacts every 5–10
bundles to make sure the journal entries stay readable and the
JSDoc + ADR coverage doesn't drift behind the code.
