# Bundle 123 — Pool play: work/ref team per match (Phase 2 of ADR 0018) (2026-05-27)

## Context

Bundle 122 shipped Phase 1 of [ADR 0018](../adr/0018-pool-play-configuration.md)
— `bestOf ∈ {1,3,5}` and the `fixed_games` schedule mode. Phase 2
covers the work/ref team requirement: in pools with an **odd** team
count there's always exactly one team sitting out each round, and
hosts want that team auto-stamped as the ref / scorekeeper so the
schedule doubles as a duty roster. Per the user's verbatim guidance
("Leave null, in that scenario a team probably won't ref"), pools
with an **even** team count get `workTeamId = null` rather than
borrowing a team from another pool — keeping the assignment local to
the pool the matches belong to.

## Decision

- **`Match` gains a mutable `workTeamId: TeamId | null` field.** Null
  default, settable post-construction so the round-grouped assignment
  pass can stamp matches without threading the work team through the
  generator's inner round-robin loop.
- **`BracketConfig.requireWorkTeam: boolean`** (default `false`). A
  per-bracket opt-in stored on the config JSON — additive, no
  migration to the `brackets` table.
- **`generatePoolPlay` learns an `assignWorkTeam` option.** After the
  per-pool round-robin / fixed-games loop runs, a private
  `assignIdleWorkTeams(matches, poolSeeds)` pass groups matches by
  `(pool, round)`, computes the set of teams playing in that round,
  and if exactly one pool team is idle, stamps `m.workTeamId = idle`
  on every match in the round. Even-sized pools (zero idle) leave the
  field null. The pass is a strict post-step; it can't change which
  matches get generated.
- **`bracket_matches.work_team_id uuid references public.teams(id)
on delete set null`**, indexed for filtering rosters.
  [supabase/migrations/20260713000000_bracket_match_work_team.sql](../../supabase/migrations/20260713000000_bracket_match_work_team.sql).
  `SupabaseBracketRepository` reads and writes the column;
  `MatchRow` hydration maps it through `as TeamId | null`.
- **Format picker grows one checkbox.** Inside the existing
  pool-play fieldset, under the schedule/games inputs:
  _"Assign a ref / work team per match (the idle team in each pool
  round)."_ `createBracketFromForm` reads `require_work_team` and
  sets `config.requireWorkTeam = true` when present. Match cards
  render a `Work team: <name>` line when `workTeamId` resolves.

## Rejected alternatives

- **Cross-pool work assignment for even pools.** Considered borrowing
  an idle team from another pool — rejected because the host would
  have to coordinate a team showing up to a court they aren't
  playing on. The user explicitly opted for "leave null" instead.
- **Storing the work team on a join table** (`bracket_match_work_teams`).
  Overkill for a single optional FK; a direct column is the same
  shape we already use for `winner_team_id`, `team_a_id`, etc.
- **Computing the work team on render.** Tempting since it's a pure
  function of seeds + round, but persisting it lets hosts manually
  override later (Phase 2b) without re-running the generator.

## Patterns surfaced

- **Round-grouped post-pass for cross-match invariants.** The pool
  generator emits matches one round-robin pair at a time, so any
  "this is true across all matches in a round" property (work team,
  later: court collisions) is cleanly expressed as a follow-up pass
  over the emitted matches grouped by `(pool, round)`. Phase 3's
  slot solver will reuse this shape.
- **`as unknown as` casts when generated Supabase types lag.** The
  hydrate path was `as MatchRow[]` — fine while every field on the
  generated row had a counterpart, broken once `MatchRow` added
  `work_team_id`. Replaced with `as unknown as MatchRow[]`; the
  generated types will catch up on the next `gen:types` run. The
  write path is unaffected (already `as never`).

## Verify

`pnpm typecheck && pnpm lint && pnpm test && pnpm build` all green.
Domain suite: 27 tests in `bracket.test.ts` (21 from Phase 1, +6 for
Phase 2: even-pool null, odd-pool stamped, fixed-games variant,
`assignWorkTeam: false` no-op, `Bracket.create` default + override).

## Follow-ups deferred

- **Phase 1b (UI reorder).** Drag-and-drop within a pool's match list
  so a host can reshuffle the generator's output without re-running.
- **Phase 2b (manual work-team override).** A small edit affordance on
  the match card so the host can swap the assigned work team for a
  specific match without touching the rest of the round.
- **Phase 3 (courts + slots).** `BracketConfig.courtLabels: string[]`,
  `Match.court`, `Match.slot`, and a greedy slot solver that respects
  "no team in two places at once" across pools sharing courts.
- **Regenerate Supabase types** (`pnpm --filter @pickupvb/supabase
gen:types`) once local Postgres is running, then drop the
  `as unknown as MatchRow[]` cast back to `as MatchRow[]`.
